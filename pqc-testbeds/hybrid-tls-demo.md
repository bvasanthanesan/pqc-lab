\# Hybrid TLS Demo (Kyber + RSA)



This project demonstrates a hybrid TLS setup using classical RSA and post‑quantum Kyber key exchange.



\## Objectives

\- Show how hybrid TLS works with both classical and PQC algorithms.

\- Highlight migration steps for organizations preparing for PQC adoption.



\## Tools \& Libraries

\- OpenSSL (classical crypto)

\- liboqs (PQC algorithms)
